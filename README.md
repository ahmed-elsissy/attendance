# منظومة الحوكمة الرقمية للحضور الأكاديمي

منصة جامعية ذكية لإدارة وحوكمة الحضور الأكاديمي عبر تقنيات البلوتوث (Bluetooth) والبطاقات اللاتلامسية (NFC) مع لوحات متابعة لحظية لمتخذي القرار والقيادات الأكاديمية.

مطبقة فعلياً ومختبرة في **كلية الطب البشري — جامعة الزقازيق** بأكثر من **572,243** عملية حضور موثقة و**8,242** طالباً وطالبة.

---

## 🌟 مميزات المنظومة

- **مرونة القنوات (5 مسارات رصد):** Bluetooth، NFC، استيراد جلسات Microsoft Teams، قائمة إلكترونية، ومسار استثنائي موثق (Manual).
- **تجربة مخصصة لكل دور:**
  - 🎓 **الطالب:** جدول تفاعلي ذكي، رصد في ثوانٍ، متابعة نسب الغياب والإنذارات، وبلاغ إلكتروني موثق.
  - 👨‍🏫 **المحاضر:** إدارة جلسات اليوم والغد، رصد في أقل من دقيقة، واعتماد القوائم وحسم البلاغات.
  - 📋 **المنسق:** رفع الجداول بصيغة Excel دفعة واحدة، مراقبة التزام الرصد، وبوابة الجاهزية قبل إصدار قرارات الحرمان.
  - 🏛️ **القيادات الأكاديمية:** لوحات معلومات لحظية وتقارير رسمية جاهزة للطباعة والاعتماد.
- **حوكمة وعدالة:** دقة رصد نهائية تتجاوز 98% وتوفير 96.7% من الوقت الإداري المهدر في الكشوف الورقية.
- **إتاحة وسرعة:** متوافقة تماماً مع معايير الويب الحديثة، تدعم الهواتف والشاشات المختلفة وتعمل بدون أي أجهزة بصمة ثابتة باهظة الثمن.

## 📁 هيكل المشروع

```text
├── index.html            # الصفحة الرئيسية الشاملة للمنظومة
├── student.html          # تجربة وصفحة الطالب الجامعي
├── lecturer.html         # تجربة وصفحة عضو هيئة التدريس
├── coordinator.html      # لوحة وعمليات المنسق الأكاديمي
├── journey.html          # الرحلة التعليمية الرقمية (5 محطات)
├── css/
│   ├── main.css          # ملف الأنماط الموحد والمضغوط
│   ├── tokens.css        # متغيرات التصميم والألوان والخطوط
│   ├── base.css          # الأساسيات وإمكانية الوصول
│   ├── components.css    # عناصر واجهة المستخدم المشتركة
│   ├── sections.css      # أقسام الصفحة الرئيسية
│   └── subpages.css      # صفحات الأدوار والرحلة
├── js/
│   └── app.js            # التفاعلات، المعرض، القوائم والأحداث
└── assets/               # الشعارات، الأيقونات ولقطات الشاشات الواقعية
```

## 🚀 المعاينة والتشغيل

المشروع عبارة عن موقع ويب ثابت (Static Site):
1. قم بفتح ملف `index.html` في أي متصفح حديث، أو استخدم أي خادم محلي مثل Live Server.
2. جاهز للنشر الفوري عبر **GitHub Pages**، **Netlify**، أو **Vercel**.
